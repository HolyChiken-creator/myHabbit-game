# myHabbit 12.18.0 — Teddy Room Master Controller

- Master controller uses the already uploaded level/background asset packs.
- Triple tap Teddy to open/close hidden room layout editor.
- Drag any furniture object or Teddy directly on the scene.
- Resize selected object with a slider.
- Switch room background level 1–4.
- For each furniture slot, choose which level's asset is used.
- Layout is saved to localStorage on the current device.
- Export JSON copies the current master layout for later server-side/deploy integration.
- Legacy generated room props are hidden while the master scene is active.
