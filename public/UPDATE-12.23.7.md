# myHabbit 12.23.7 — profile JSON persistence fix

## Що виправлено
- Session bootstrap більше не перетирає локально збережені зміни профілю серверною копією.
- Якщо є pending JSON налаштувань, сервер спочатку лише підтверджує сесію; локальний state лишається джерелом відображення до безпечної синхронізації.
- Якщо base revision не змінився, pending profile JSON синхронізується ще під час bootstrap.
- При 409-конфлікті локальний пакет більше не видаляється і не замінюється серверним state: чернетка профілю залишається на пристрої.
- «Зберегти JSON входу» та захищений JSON тепер формуються безпосередньо з актуального state у памʼяті після підтвердженого persist, а не з потенційно застарілого запису сховища.

## Результат
Зміна профілю → локальне збереження → перезавантаження сторінки більше не повинні повертати стару серверну версію. Session loading gate 12.23.6 при цьому збережено.
