# myHabbit 12.23.6 — session bootstrap gate

## Що виправлено
- Авторизований dashboard більше не рендериться з demo/seed-профілем до перевірки сесії.
- Під час старту користувач бачить брендований loading screen, доки сервер не підтвердить реальний профіль.
- `/api/family/state` виконується до першого authenticated paint.
- Якщо мережа недоступна, дозволяється тільки підтверджений локальний профіль цього самого `auth.userId`; demo seed як fallback для реальної сесії не показується.
- Якщо токен відхилено сервером, застаріла активна сесія прибирається і застосунок повертається на публічний екран.
- Якщо немає ні сервера, ні валідного локального профілю, показується окремий екран повторного підключення замість тестового акаунта.
- Boot watchdog тепер чекає явний `myhabbit:ready`, а не ховає splash через будь-який HTML у `#app`.

## UX
Послідовність запуску тепер: splash → перевірка сесії → реальний профіль/кімната → головний інтерфейс. Ім'я, баланс та аватар тестового користувача не повинні мигати під час завантаження.
