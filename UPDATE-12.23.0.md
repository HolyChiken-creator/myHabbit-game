# myHabbit 12.23.0 — Vertical Teddy room workshop

## What changed

- Teddy's room workshop now follows one top-to-bottom page flow instead of forcing the user through one decor category at a time.
- The room stays at the top of the workshop so a user can preview the result, then continue scrolling down through the complete decor catalog.
- Every decor category is rendered in the same vertical catalog: background, window, armchair, table, bookshelf, fireplace, rug, plant, painting, floor lamp and clock.
- Each item card supports live preview and a direct Buy / Equip action without needing to leave the catalog.
- Owned, equipped, locked and unaffordable states are visible on each item card.
- Quick category chips remain available only as navigation shortcuts; normal vertical page scrolling is no longer intercepted by the chip row.
- Preview/equip rerenders preserve the user's page scroll position.
- Desktop keeps the room preview sticky while browsing the long catalog; mobile uses natural page scrolling so the room does not consume most of the screen.
- Added a "Back to Teddy's room" action at the bottom of the workshop.

## Compatibility

The room economy, purchase rules, prerequisite tiers, magical Teddy upgrade reaction, global owner master-layout and device layout synchronization are unchanged.
