# myHabbit 12.7.0 — Live Teddy Room preview

This update replaces the room decoration modal flow with a non-blocking live studio.

## What changed
- Teddy Room stays visible while decorating.
- Desktop: the decoration studio opens beside the room.
- Mobile/tablet: the studio moves below the room instead of covering it.
- Any style can be previewed instantly before purchase.
- Preview never spends crystals and never changes saved room state.
- Locked future tiers can still be previewed, but cannot be purchased until prerequisites are owned.
- Owned styles can be previewed and re-equipped without repurchase.
- Purchase/equip requires an explicit confirmation button.
- Revert preview restores the currently equipped room instantly.
- Closing the studio always discards the temporary preview.

## UX rule
Preview first, pay only after confirmation. The player must always be able to see Teddy and the room while comparing styles.
