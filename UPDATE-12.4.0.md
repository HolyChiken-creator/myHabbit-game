# myHabbit-game 12.4.0 — Room Workshop + Match-3 Variety

## Що змінилось

- Діаманти повернуті як окрема ігрова валюта для оформлення особистого простору Тедіка.
- Для старих профілів, де поля `diamonds` ще немає, додається стартовий баланс 40 💎 без перезапису вже наявного балансу.
- Додана **Майстерня кімнати** з 8 категоріями: стеля, стіни, підлога, стіл, наповнення столу, килим, кутовий декор і освітлення.
- Куплений декор зберігається назавжди; відкриті предмети можна вільно перевстановлювати без повторної оплати.
- Сцена з Тедіком стала вищою та багатошаровою: додані перспектива, тіні, освітлення, килим, стіл, пропси і візуальні варіанти для кожної категорії декору.
- Match-3 тепер має різні розміри поля (6×6, 7×7, 8×8), теми, палітри, кількість ходів, цілі та прогресію складності.
- Додані бустери: 🔨 молоток, 🔀 перемішування, 🔥 повне спалення поля.
- Вогняний бустер анімує загоряння всього столу, знищення фішок і появу нового поля.
- За проходження Match-3 тепер видаються діаманти: 1 за звичайний рівень, 3 за mini-boss, 5 за boss і 8 за grand boss.
- Старі Match-3 сесії автоматично мігрують на нову схему, щоб не тягнути однакові старі поля у новий режим.
- Release audit більше не містить застарілу захардкоджену версію й перевіряє `VERSION`, `package.json`, PWA manifest і `public/VERSION.txt` між собою.

## Файли оновлення

Основні зміни: `public/app.js`, `public/game-rules.js`, `public/home.css`, PWA/version files, Match-3 tests і release audit.

## Перевірка перед деплоєм

```bash
npm install
npm run check
npm run validate
node scripts/test-match3.mjs
npm run audit
```
