myHabbit 12.1.1 CORE RPG UPDATE

1. Розпакуйте архів у корінь гілки HolyChiken-creator-patch-2 із заміною файлів.
2. Виконайте npm run check && npm run validate.
3. Задеплойте через npm run deploy / wrangler deploy.

Що змінено:
- кожен користувач може створити власне RPG-завдання з XP/монетами;
- кожен користувач може створити власну реальну нагороду та купити її за монети;
- особисті задачі/нагороди бачить лише їх власник;
- досягнення тепер показуються компактним toast у правому верхньому куті;
- Тедик більше не накопичує чергу повідомлень про досягнення;
- додано PACK-09B та PACK-10A assets.
